## Local-only files

The files below are contained in the atak-civ.zip that was downloaded. Please add only these files to the repo to avoid breaking the code. They are already included in the .gitignore so will be specific to your machine.

The following files are not committed to GitHub because they are machine-specific or too large:

- `local.properties`
- `.gradle/`
- `.idea/`
- `*.apk`
- `atak-gradle-takdev.jar`
