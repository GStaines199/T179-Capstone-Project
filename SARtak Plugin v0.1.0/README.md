PURPOSE AND CAPABILITIES

SARtak is an ATAK plugin being developed to reduce setup friction and improve the reliability of basic team awareness in field operations. The initial goal is to ensure that when a user installs ATAK and the plugin, their device can automatically begin participating in team awareness with minimal or no manual configuration.

The current intended Version Zero focus is:
- automatic capture of GNSS location data
- integration with ATAK using supported plugin interfaces
- automatic or simplified position sharing behaviour
- local track logging
- clear handling of degraded or failed location states
- low user interaction requirements

This plugin is being developed as part of a capstone project and is intended to prioritise reliability, simplicity, and operational usefulness over feature breadth.


_________________________________________________________________
STATUS

In Progress.

This plugin is currently in early development as part of the IT Capstone project. Initial work is focused on:
- setting up the ATAK development environment
- running ATAK successfully in an emulator/development environment
- reviewing ATAK plugin structure and example plugins
- establishing the base plugin template and repository structure

Version Zero is not yet released. At this stage it is intended for internal development, testing, and demonstration use only.
